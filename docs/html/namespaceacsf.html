bool isHeartBeat )

Builds the bytes put on the wire: a 4 byte big endian header followed by the body. The top bit of the header marks a heartbeat; the other 31 bits hold the body length.

Parameters
bodyMessage body.
isHeartBeatTrue for a heartbeat (the body may then be empty).
Returns
The frame, or std::nullopt if the body is too large or is empty and not a heartbeat.

Variable Documentation

◆ READ_TIMEOUT_MS

std::chrono::milliseconds acsf::READ_TIMEOUT_MS {15000}
inline

Global timeouts in milliseconds, shared by every server and client. Change them with setTimeout().

  • READ_TIMEOUT_MS: max wait for the next message to start arriving (default 15000)
  • READ_BODY_TIMEOUT_MS: max wait for the rest of a message once its header arrived (default 60000)
  • SEND_TIMEOUT_MS: max time to finish sending one message (default 60000)
  • SERVER_HEARTBEAT_TIMEOUT_MS: max time a connection may stay silent before it is dropped (default 45000)
  • HEARTBEAT_RATE: how often heartbeats are sent (default 15000)
