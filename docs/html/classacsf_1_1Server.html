Detailed Description

A TCP server that accepts many clients and exchanges length-prefixed messages with them.

The server runs its own I/O thread. Every client gets a numeric id (0, 1, 2, ...) in connection order. Incoming messages from all clients arrive through receive(), tagged with the sender's id in Message::isFrom. Reply to a specific client with send().

acsf::Server server(15555, []{});
server.start();
while (auto msg = server.receive()) {
server.send(msg->isFrom, "echo: " + msg->payload);
}
server.stop();
